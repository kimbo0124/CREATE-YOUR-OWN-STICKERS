# 🎨 CREATE YOUR OWN STICKERS

*A simple and a fun web app where you can **DRAW, DOODLE, SCRIBBBLE OR EVEN WRITE OUT THINGS AND CONVERT THEM AS YOUR OWN STICKERS** and save them to your personal sticker gallery. The idea is to keep sticker-making easy and creative, without needing any complicated software or setup :3*

## ✏️ HOW TO USE :)

1. Open the website.
2. Use the drawing area to create your own sticker.
3. Add your own colors and designs to make it yours.
4. When you're happy with it, click on **MAKE STICKER**.
5. Then click on **DOWNLOAD STICKER** to download it.
6. Lastly your finished sticker will be added to your **sticker gallery**, where you can view the stickers you've created.

It's meant to be simple: **draw → save → collect your stickers.** 🎨

## 💻 RUN LOCALLY

Want to run the project on your own computer?

```bash
git clone https://github.com/kimbo0124/CREATE-YOUR-OWN-STICKERS.git
```

Then open the project folder and simply open **`index.html`** in your web browser.

*VIOLA !* there are **no packages to install and no build setup required**.
